# Binary-mask topology and protected-source cost (10 November 2026)

Issue: #1. Complementary to draft PR #2; this branch does not alter that PR or production cleaning.

Two synthetic diagnostics: (1) 4-connected component areas of a predicted cosmic-ray mask (diagonal contact is **not** connectivity), and (2) explicit partition of missed true CR pixels, falsely masked background, and falsely masked source-core pixels. A weighted loss exposes the chosen source-preservation penalty rather than hiding it inside a single accuracy number.

The source-core mask and CR truth are assumed disjoint. A cost weight is a decision preference, not a measured astronomical loss function. These functions do not quantify photometric bias or HST cosmic-ray incidence. The included SVG is a deterministic illustrative cost curve for one false core pixel, one missed CR and one false background pixel.

Reproduce: `python -m unittest discover -s research -p 'test_component_audit_20261110.py' -v` from repository root. No external data or dependencies.
